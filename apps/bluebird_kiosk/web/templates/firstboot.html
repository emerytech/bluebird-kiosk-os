BlueBird Kiosk OS

First-time setup

Welcome

This wizard will connect the kiosk to your network, link it to your school, and set an admin PIN. It takes about two minutes.

Network

Choose a WiFi network, or skip if you've already plugged in an Ethernet cable.

Scanning…

School identity

Enter your BlueBird school slug. This is the short identifier in your school's URL, e.g. nen in bluebird-alerts.com/nen/legacy-wall.

Admin PIN

Set a 6-digit PIN for the device-admin overlay. Used by on-site staff to fix WiFi or display issues. Different from the in-app kiosk PIN.

All set

Setup complete. This kiosk will reboot in a moment and start showing Legacy Wall automatically.
